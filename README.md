# Frontend — Movie Review System

## Getting Started

1. Open this folder in your terminal:
   \\\ash
   cd frontend
   \\\

2. Install dependencies:
   \\\ash
   npm install
   \\\

3. Run the development server:
   \\\ash
   npm run dev
   \\\

The app will launch at **http://localhost:5173** with live reload and automatic API proxy to the Spring Boot backend!
